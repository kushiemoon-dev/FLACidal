# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

Found a security issue? Please disclose it responsibly:

1. Skip the public GitHub issue — **don't** file one
2. Send an email to **kushie.dev@icloud.com**
3. Where possible, include reproduction steps
4. Expect a reply within 48 hours
